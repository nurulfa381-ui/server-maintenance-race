# SERVER HERO RACE™ v2.0 Multiplayer Classroom Edition

1. Upload semua fail ke root repository GitHub.
2. Guru buka `teacher.html`.
3. Guru masukkan nama dan kod bilik, kemudian buka bilik.
4. Pelajar buka `index.html`, masukkan kod bilik, nama dan ID.
5. Guru klik `APPROVE ALL`, kemudian `START RACE`.
6. Selepas tamat, guru klik `TAMATKAN` dan boleh eksport CSV.

Nota: Projek ini menggunakan Firebase Realtime Database yang telah dikonfigurasi.
